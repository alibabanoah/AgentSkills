# christian-theology-harness

西方神学·基督神学·宗教哲学·东方智慧 深度研究 Harness。

## 覆盖领域

- 教父神学、经院哲学、宗教改革、现代神学、后现代神学
- 基督教核心教义：三位一体、基督论、救恩论、创世论、末世论
- 宗教哲学：上帝存在证明、恶的问题、宗教语言、信仰与理性
- 存在主义与现象学神学：克尔凯郭尔、海德格尔、列维纳斯、马里翁
- 道德经与道家思想：道论、德论、无为、天道创世观
- 佛教与禅宗：四圣谛、缘起论、空性、佛性、禅宗、净土宗、天台华严
- 跨文明对话：道与Logos、无我与位格、空性与否定神学、慈悲与Agape、无为与恩典

## 使用方式

```bash

cp -r christian-theology-harness ~/.hermes/skills/

# Claude Code
cp -r christian-theology-harness ~/.claude/skills/
```
